# Wheel of Fortune

[Русский](doc/README.ru.md)

A simple weighted wheel of fortune with a `tkinter` GUI, elimination mode, and convenient bulk import.
Python 3.10+ (tested on 3.14), no third-party dependencies.

![Screenshot of the wheel app](doc\screenshot.jpg)

## Launch

```bash
python main.py
```
Or with uv:
```bash
uv run main.py
```

## Features

- Bulk import: csv (file or paste), options and weights in two dialog windows.
- Weighted options.
- Configurable spin duration.
- Elimination mode.

## Import format

**File / CSV paste** — one line per option, separator `;` or `,`:

```
Jackpot, 1
Prize 1, 3
Empty
Small change, 20
```

Weight is optional (defaults to 1). Lines starting with `#` are comments.

**Two steps** — first a list of names (one per line), then a list of weights.
The number of lines must match.
